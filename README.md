Countdown Timer

A simple countdown timer for study sessions, built with HTML, CSS and JavaScript while I learn JS. It started as a Study Tracker, and the timer is the first part.

Features

Tick a box (change [ ] to [x]) only when the feature really works.

 [X]Shows the time left as mm:ss
 Counts down every second
 Start button
 Pause button
 Reset button
 Stops at 00:00
How to run
Download or clone this repository.
Open index.html in a web browser.

There is nothing to install.

What I'm learning
Functions and variables
Turning seconds into minutes and seconds
setInterval and clearInterval
Responding to button clicks and updating the page (DOM and events)
Using Git and GitHub to save my progress
